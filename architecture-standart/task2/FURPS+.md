| Код    | Требования                                                                                                               | Комментарий                             |
|--------|--------------------------------------------------------------------------------------------------------------------------|-----------------------------------------|
| **F**  | **Функциональные (Functionality)**                                                                                       |                                         |
| F1     | Клиент может подать заявку на депозит через сайт (ФИО + телефон).                                                        |                                         |
| F2     | Клиент может подать заявку на депозит в интернет-банке (с подтверждением по СМС).                                        |                                         |
| F3     | Система отображает актуальные ставки для новых клиентов (сайт) и персонализированные — для существующих (интернет-банк). |                                         |
| F4     | Кол-центр получает заявки с сайта и интернет-банка.                                                                      |                                         |
| F5     | Бэк-офис обрабатывает заявки в АБС (ручной режим в MVP).                                                                 |                                         |
| F6     | Клиент получает СМС-уведомления на всех этапах (подтверждение, открытие депозита).                                       |                                         |
| F7     | Функционал работы со ставками должен быть реализован в АБС                                                               |
| **U**  | **Удобство использования (Usability)**                                                                                   |                                         |
| U1     | Интерфейс должен соответствовать корпоративному дизайну (цвета, шрифты).                                                 |                                         |
| U2     | Время отклика интерфейса сайта и ИБ < 1000 мс.                                                                           |                                         |
| U3     | Простота подачи заявки.                                                                                                  |                                         |
| **R**  | **Надёжность (Reliability)**                                                                                             |                                         |
| R1     | Доступность систем 24/7 (99.9% uptime).                                                                                  |                                         |
| R2     | Защита от перегрузки АБС (ограничение числа одновременных запросов).                                                     |                                         |
| R2     | Автоматическое переключение на резервный ЦОД при сбое.                                                                   |                                         |
| R2     | Предусмотреть равномерное горизонтальное масштабирование и распределение запросов между серверами, приложениями и ЦОД    |                                         |
| **P**  | **Производительность (Performance)**                                                                                     |                                         |
| P1     | Отклик по всем операциям на сайте и ИБ должен быть ≤ 1 сек.                                                              |                                         |
| P2     | АБС должна выдерживать текущую нагрузку и возможное увеличение трафика                                                   |                                         |
| P3     | СМС-уведомления доставляются ≤ 60 сек.                                                                                   | Пользователь не должен ждать СМС дольше |
| **S**  | **Поддерживаемость (Supportability)**                                                                                    |                                         |
| S1     | Использование существующих технологий (MS SQL, Oracle, Java Spring Boot).                                                |                                         |
| S2     | Выполнить доработку функционала СМС силами команды разработки банка                                                      |                                         |
| S3     | Перевод ИБ на микросервисную архитектуру в рамках задачи открытия депозитов                                              |                                         |
| S4     | Разработка документации системы                                                                                          |                                         |
| S5     | Логирование всех этапов обработки заявки.                                                                                | Аудит и отладка.                        |
| **+R** | **+ Ограничения (Restrictions)**                                                                                         |                                         |
| R1     | Запрет прямой интеграции интернет-банка с АБС (использовать промежуточный слой).                                         |                                         |
| R2     | Шифрование данных при передаче между системами (SSL/TLS).                                                                |                                         |
| R3     | Обеспечить совместимость ИБ с Kafka для асинхронной обработки заявок.                                                    |                                         |
| R3     | При доработках во всех системах нужно как можно больше использовать технологии, которые уже есть в банке                 |                                         |
| R4     | Новые технологии (если они потребуются) должны быть совместимы с существующими платформами разработки                    |                                         |
| R5     | Внутри банка уже должна была экспертиза — сотрудники понимали новые технологии хотя бы на уровне языков программирования |                                         |
